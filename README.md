# 北京中轴线·古都美学交互网页

B 赛道「古都美学」方向的 PC 端交互网页项目。以北京中轴线为载体，制作分层插画与滚动视差结合的探索体验。

## 协作方式

1. 在 GitHub 仓库页面接受协作者邀请后，克隆仓库到自己的电脑。
2. 技术组把网页代码放在仓库内；美工组把已确认可用的网页素材放入 `assets/`，并记录来源和授权。
3. 每次开始修改前先拉取最新内容；完成后提交并推送。多人同时修改同一文件时，先在群里沟通。

## 美工素材交付

- 仅制作 PC 端，设计主画布为 1920 × 1080；同时检查 1366 × 768 窗口的关键内容是否完整。
- 场景远景、地面、近景分别导出；背景优先 WebP，需透明且单独运动的建筑和物件用 PNG，简单线条和图标用 SVG。
- 保留 Figma、PSD 等分层源文件，并提供每屏的层级、位置和交互标注。
- 文案以可复制文本提交。每个遗产点位记录史实来源；图片记录作者、授权方式和 AI 生成情况。

项目代码和场景素材将在确认第一版设计后逐步加入。
