# 北京中轴线·古都美学交互网页

B 赛道「古都美学」方向的 PC 端交互网页项目。以北京中轴线为载体，制作分层插画与滚动视差结合的探索体验。目前为可交互原型，建筑是代码绘制的示意图，不是史实复原图。

## 运行

项目使用原生 HTML、CSS、JavaScript，不需要安装依赖。直接打开 `index.html` 即可预览。若浏览器限制本地资源，可在项目目录运行 `python -m http.server 8000`，再访问 `http://localhost:8000`。

目前包含开场、四段滚动场景、建筑热点与介绍弹层、互动问答、资料来源。建议在 1920 × 1080 或 1366 × 768 的 PC 浏览器窗口演示。

## 协作方式

1. 在 GitHub 仓库页面接受协作者邀请后，克隆仓库到自己的电脑。
2. 每项任务从最新的 `main` 新建分支，例如 `feature/palace-art` 或 `feature/axis-motion`。提交完成后发 Pull Request，检查通过再合并到 `main`。
3. 技术组把网页代码放在仓库内；美工组把已确认可用的网页素材放入 `assets/`，并记录来源和授权。多人同时修改同一文件时，先在群里沟通。

## 美工素材交付

- 仅制作 PC 端，设计主画布为 1920 × 1080；同时检查 1366 × 768 窗口的关键内容是否完整。
- 场景远景、地面、近景分别导出；背景优先 WebP，需透明且单独运动的建筑和物件用 PNG，简单线条和图标用 SVG。
- 保留 Figma、PSD 等分层源文件，并提供每屏的层级、位置和交互标注。
- 文案以可复制文本提交。每个遗产点位记录史实来源；图片记录作者、授权方式和 AI 生成情况。

## 场景素材接入

`main.js` 顶部的 `scenes` 数组统一管理四段场景的主题、标题、说明和热点。每个热点有 `x`、`y` 百分比位置、介绍文案与来源链接。更换插画时，请保持场景的南北顺序与东西位置准确。

每张需要独立运动的建筑或物件单独导出透明 PNG/WebP；图标和简单纹样导出 SVG。当前场景使用 `landmarkSvg()` 输出示意建筑；正式素材到位后，可将对应的 `<img>` 放入 `#landmark-art`，并为场景添加远景、前景图层。每次新增事实性文案需附可核验来源。
